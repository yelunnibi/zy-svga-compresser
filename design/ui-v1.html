1这版改了什么（相对现状）

  • 动作不再重复。原来顶部有「压缩选中 / 保存为副本 / 覆盖原文件」，底部又有「保存当前为副本 / 覆盖当前并备份」——同一件事两个入口。现在只剩 压缩（试算，不落盘）和 保存 ▾（落盘，三种模式收进下拉）。
  • 「对谁生效」写进按钮。勾了文件就显示「压缩 · 3 项」，没勾就是「压缩当前」，不用再猜。
  • 参数面板加宽到 296px（原 220px），控件不再挤成两三行。分组可折叠，非 SVGA 文件时不再留一块空白说明。
  • 预览区还给预览。原来下面那块数据区最高占 46% 且自己滚动，把预览越挤越小；现在数据压成一条横排结果条。
  • 体积与内存并排同权重，内存带阈值标尺。这是这个工具唯一真正"危险"的指标。
  • 改用主题变量。原代码把 #333 / #252526 硬编码，浅色主题下整个面板是黑的——点右上角「浅色」可验证。

?需要你拍板的 5 件事

  • 参数放哪：右上角切「方案 A / 方案 B」。A = 右侧常驻栏；B = 底部抽屉四列横排，预览更大。我倾向 B，因为参数是"调一次就不动"的东西，不值得长期占 296px 宽。
  • 「画布与布局」的标注：现在标的是「体积 + 内存」，但我核对过实现——它只缩放坐标，不动纹理像素，两个指标都不省。我改成标「播放尺寸」。你认不认这个判断？
  • 丢帧能否省内存：严格说，抽掉帧后若某些纹理已无引用，仍会留在包里被解码。要真省内存就得同时清理无引用纹理。现在只标了「体积」。要不要我加上纹理回收？
  • 结果条要不要常驻：现在是预览下方一条。也可以做成悬浮在预览右下角的小卡，预览区再大一点。
  • 底部状态栏：现在还有 6 项统计 + 备份 + TinyPNG 用量，信息偏杂。要不要精简成 3 项？
